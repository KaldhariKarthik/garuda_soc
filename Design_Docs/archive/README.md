# Archived design documents

Rev 1.x / 2.0 block documents and the original team deck, kept for history.
They are superseded by the Rev 4.0 set one level up (`GARUDA-*-SPEC-001.md`,
`GARUDA-TRM-001.md`, `GARUDA-ADR-001.md`, `garuda_system.yaml`).
Where the two disagree, the Rev 4.0 set and `Docs/DECISIONS.md` win.

`DSU/DSU_Verification_reports/` is verification evidence, not a spec, and is
still current for the DSU sub-blocks.
