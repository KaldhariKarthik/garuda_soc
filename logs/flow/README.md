# logs/flow: Runner self-tests, oracle negative controls, tool checks

Owner of the content: shared (Track A drafts, both review). Convention: [`Docs/handbook/H2_running.md`](../../Docs/handbook/H2_running.md), "Log convention".

| Path | What | In git |
|---|---|---|
| `summary/<suite>.tsv`, `.txt` | One row per test of the last full suite run | yes |
| `evidence/` | Only logs and records cited by sign-off (1 MB cap per file) | yes |
| `history.tsv` | One row per test run, appended | yes |
| `raw/` | Per-run logs, builds, waves, coverage databases | no |
